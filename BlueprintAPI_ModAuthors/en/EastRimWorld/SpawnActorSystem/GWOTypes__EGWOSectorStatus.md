## Functional description (from header comments)

> Runtime status of a sector (active / cache / idle / inactive)

## Enumerators

| Value | Display name | Description |
|------|------|------|
| `ACTIVE` | Active | Active: the sector is within the active processing range |
| `CACHE` | Cache | Cache: the sector is in the cache range around the active area |
| `IDLE` | Idle | Idle: the sector is temporarily not being processed |
| `INACTIVE` | Inactive | Inactive: the sector is not active (default) |
