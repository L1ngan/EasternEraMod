# `enum` `EModStorageSpace`

**源码头文件:** `CreateModPlugin/Public/ItemDataStruct.h`

---

## 功能说明（来自头文件注释）

> 存储空间类型枚举（露天/屋檐下/室内），用于配置物品在不同存储空间下的保质期衰减率

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 未指定存储空间 |
| `OutDoor` |  | 露天存储 |
| `UnderRoof` |  | 屋檐下（有顶棚）存储 |
| `InDoor` |  | 室内存储 |
