# `enum` `EExchangeMartialArtsResult`

**源码头文件:** `EastRimWorld/PostStation/PostStationStruct.h`

---

## 功能说明（来自头文件注释）

> 切磋结束结果(EndExchangeMartialArts 广播时随实例带出; None=未分胜负结束, 如超时未到场取消/开始前角色死亡/读档角色缺失)

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 未分胜负结束（如超时未到场取消/开始前角色死亡/读档角色缺失） |
| `PlayerWin` |  | 玩家切磋获胜 |
| `PlayerFailed` |  | 玩家切磋失败 |
| `Cancelled` |  | 切磋被取消 |
