# `enum` `EGWODebugVisual`

**源码头文件:** `EastRimWorld/SpawnActorSystem/GWOTypes.h`

---

## 功能说明（来自头文件注释）

> 生成器调试可视化的显示内容级别

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `NONE` | None | 不显示任何调试可视化 |
| `ALL` | All | 显示全部调试信息 |
| `BOX_AND_POINTS` | Box and Points | 仅显示生成箱体与生成点 |
| `ONLY_POINTS` | Only Points | 仅显示生成点 |
