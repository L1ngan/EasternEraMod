# `enum` `EEmergentEventCategory`

**源码头文件:** `EastRimWorld/System/Emergence/Data/EmergenceTypes.h`

---

## 功能说明（来自头文件注释）

> 涌现事件题材分类 — 策划案 §4 的 13 类。
> 事件库(DT_EmergentEvents)每行用此枚举归类; 题材权重表按此分类挂权重。

| 值 | 显示名 | 说明 |
|------|------|------|
| `FactionConflict` | 势力冲突与兴衰 | Faction Conflict。 |
| `Anecdote` | 江湖轶闻 | Anecdote。 |
| `Treasure` | 秘境探宝 | Treasure。 |
| `Tournament` | 比武 | Tournament。 |
| `Assassination` | 暗杀阴谋 | Assassination。 |
| `Diplomacy` | 联姻外交 | Diplomacy。 |
| `Disaster` | 灾变 | Disaster。 |
| `Apprenticeship` | 历练联动 | Apprenticeship。 |
| `Settlement` | 据点经营 | Settlement。 |
| `Dominion` | 城内门派 | Dominion。 |
| `Homeland` | 家园内政 | Homeland。 |
| `JustEvil` | 正邪对立 | Just Evil。 |
| `ContentHook` | 内容钩子 | Content Hook。 |
| `MAX` |  | 枚举上限哨兵值，仅用于内部边界判断。 |
