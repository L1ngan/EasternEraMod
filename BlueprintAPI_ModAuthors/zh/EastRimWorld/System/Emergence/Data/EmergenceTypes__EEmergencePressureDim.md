# `enum` `EEmergencePressureDim`

**源码头文件:** `EastRimWorld/System/Emergence/Data/EmergenceTypes.h`

---

## 功能说明（来自头文件注释）

> 涌现压力维度 — 策划案 §2 的 10 个正向压力维度。
> 每个维度做两件事: ① 决定题材(压力越高对应题材越容易冒) ② 指向对象(记下令它最高的具体对象)。
> 注意: 这是"正向压力"。反向闸门(防刷屏)单独用 FEmergenceReverseGate 表达, 不在此枚举内。
> ⚠️ 存档稳定性: 本枚举作 FEmergencePressureSnapshot::Pressures 的 TMap key 入档,
>    序列化按数值。**只可在 MAX 前追加新维度, 不可重排/插入中段**, 否则旧档键值错位。

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `Realm` | 境界压力 | 玩家宗门越强, 江湖该出配得上的对手/机缘 |
| `Silence` | 沉寂压力 | 某地太久没出事, 世界显得"假" |
| `Feud` | 结仇压力 | 两派积怨深, 该火并/复仇 |
| `RiseFall` | 兴衰压力 | 势力的生死是江湖最大的戏 |
| `Hegemon` | 独大压力 | 某势力坐大, 逼近一统 |
| `Order` | 治安压力 | 据点经营崩坏是城镇层面的强戏 |
| `Disciple` | 弟子压力 | 弟子是玩家最有依恋感的对象 |
| `Homeland` | 家园压力 | 自家宗门作为整体的崩溃戏(玩家专属) |
| `Disaster` | 灾害压力 | 季节×区位×脆弱度, 有因果的灾变 |
| `Dullness` | 沉闷压力 | 兜底维, 再太平也总得有点动静 |
| `None` |  | 事件行 PrimaryPressure=None: 不判压力, 只由其他门槛(启用/境界/冷却/并发)过滤, 轮盘按底权参与 |
| `MAX` |  | 维度数量哨兵(遍历用), 不是真实维度 |
