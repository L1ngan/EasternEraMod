# `enum` `ELordAttackPermission`

**源码头文件:** `EastRimWorld/System/Dominion/DominionTypes.h`

---

## 功能说明（来自头文件注释）

> 城主对玩家攻打城内门派的态度许可

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `Refuse` |  | 拒绝(关系不足;玩家仍可强行攻打,代价是关系大幅恶化) |
| `Reluctant` |  | 勉强同意(关系一般;会降低城主对玩家的态度) |
| `Acquiesce` |  | 默许(关系良好) |
