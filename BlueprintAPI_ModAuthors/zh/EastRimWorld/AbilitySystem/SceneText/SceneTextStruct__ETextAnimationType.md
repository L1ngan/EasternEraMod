# `enum` `ETextAnimationType`

**源码头文件:** `EastRimWorld/AbilitySystem/SceneText/SceneTextStruct.h`

---

## 功能说明（来自头文件注释）

> 场景文字的动画类型

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 无动画 |
| `Linear_Up` |  | 直线向上飘动 |
| `Linear_Down` |  | 直线向下飘动 |
| `Linear_Left` |  | 直线向左飘动 |
| `Linear_Right` |  | 直线向右飘动 |
| `Linear_LeftRightOnly` |  | 仅在左右方向随机直线飘动 |
| `Linear_Random` |  | 随机方向直线飘动 |
| `Parabolic_Up` |  | 抛物线向上飘动 |
| `Parabolic_Down` |  | 抛物线向下飘动 |
| `Parabolic_Left` |  | 抛物线向左飘动 |
| `Parabolic_Right` |  | 抛物线向右飘动 |
| `Parabolic_Random` |  | 随机方向抛物线飘动 |
| `Random_Cardinal` |  | 在上下左右四个正方向中随机飘动 |
| `Random` |  | 完全随机方向飘动 |
