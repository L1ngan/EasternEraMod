# `enum` `EChatTimerType`

---

## 功能说明（来自头文件注释）

> 聊天相关定时器类型枚举。

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `ChatInterval` |  | 完成一次聊天后到下一次尝试查找聊天对象的间隔定时器。 |
| `EndChatting` |  | 控制聊天结束的定时器。 |
| `FindChatPartner` |  | 控制查找聊天对象间隔的定时器。 |
| `UpdateChatting` |  | 控制聊天进行中更新间隔的定时器。 |
