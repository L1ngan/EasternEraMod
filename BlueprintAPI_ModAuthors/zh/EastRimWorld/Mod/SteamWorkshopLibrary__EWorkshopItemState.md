# `enum` `EWorkshopItemState`

**源码头文件:** `EastRimWorld/Mod/SteamWorkshopLibrary.h`

---

## 功能说明（来自头文件注释）

> Workshop 项目状态

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` | None | 无状态（未订阅、未安装） |
| `Subscribed` | Subscribed | 已订阅 |
| `LegacyItem` | Legacy Item | 旧版（Legacy）创意工坊项目 |
| `Installed` | Installed | 已安装到本地 |
| `NeedsUpdate` | Needs Update | 已安装但需要更新 |
| `Downloading` | Downloading | 正在下载 |
| `DownloadPending` | Download Pending | 等待下载（已加入下载队列） |
