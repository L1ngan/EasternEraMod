# `enum` `EItemUseState`

**源码头文件:** `EastRimWorld/Struct/ItemStruct.h`

---

## 功能说明（来自头文件注释）

> 物品被使用的状态

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 未使用 |
| `BeEquipped` |  | 被装备着（穿在身上） |
| `BeHeld` |  | 被拿着（拿在手上） |
| `InTradeArea` |  | 在交易区 |
| `CharacterOwned` |  | 角色拥有（耗材归属于该角色 行为触发时可被自动使用） |
