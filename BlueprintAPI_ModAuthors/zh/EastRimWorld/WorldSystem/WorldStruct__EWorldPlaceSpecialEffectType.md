# `enum` `EWorldPlaceSpecialEffectType`

**源码头文件:** `EastRimWorld/WorldSystem/WorldStruct.h`

---

## 功能说明（来自头文件注释）

> 地点特殊效果类型（全局效果，每个 AWorldPlace 独立数值）

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 未指定或无效的默认值。 |
| `AddFactionGlobalBuff` |  | 添加对应阵营的全局 Buff，参数为 Buff ID |
| `JianghuReputationEfficiency` |  | 江湖声望获取效率增加 |
| `PlantingTerrainBonus` |  | 种植地形加成 |
| `ShoppingPriceChange` |  | 购物价格变化 正值为增加 负值为减少 |
