# `enum` `EWorldBattleRuntimeTeamRole`

**源码头文件:** `EastRimWorld/WorldSystem/WorldSectBattleSystem/WorldBattleRuntimeStruct.h`

---

## 功能说明（来自头文件注释）

> World Battle Runtime Team Role 枚举类型。

## 枚举值

| 值 | 显示名 | 说明 |
|------|------|------|
| `None` |  | 未指定队伍职责。 |
| `Attack` |  | 进攻方。只会影响进攻点出生和占旗攻方计数。 |
| `Defense` |  | 防守方。存在防守方时，旗子开局默认归防守方且满条。 |
| `Neutral` |  | 中立方。只参与场上战斗，不参与占领进度计算。 |
